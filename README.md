# War2Mod (Rust)

Шаблон (SDK) для создания синглплеерных модов к **Warcraft II: Battle.net Edition 2.02** — порт [оригинального C++ проекта](https://github.com/Mistral-war2ru/War2Mod) на Rust.

Результат сборки — файл `victory.w2p` (32-битная DLL), который загружается игрой как плагин и в рантайме патчит её код: добавляет новые механики, кнопки, исправления ИИ и позволяет писать собственные победные условия для всех 52 миссий кампаний и пользовательских карт.

## Что умеет мод

- **Новые механики**: захват зданий и юнитов, порталы с телепортацией, рунные камни с аурами, ауры юнитов (замедление, вампиризм, невидимость и др.), постройка героев из ратуши, выращивание леса и золотых шахт, демон из круга, овцы с ферм.
- **Интерфейс**: rally points (точки сбора для зданий, правый клик), кнопка автохила в церкви, кнопка «боевые рабочие» в ратуше, третья кнопка строительства у рабочих, показ убийств вместо скорости в панели юнита.
- **Сеть**: команды autoheal и «боевые рабочие» синхронизируются между игроками в мультиплеере через чит-пакеты игры (работает, если мод установлен у всех игроков; флаг читера не выставляется).
- **Фиксы движка и ИИ**: pathfinding, multicast, save/load ИИ, powerbuild, поведение сапёров, расцепление застрявших юнитов и др.
- **Свои триггеры победы**: 52 слота под миссии кампаний + `v_custom` для пользовательских карт. Примеры — в `src/victory.rs` (закомментированные example1–6).

> **Важно**: мод только для синглплеера и игр, где он установлен у всех участников. Адреса привязаны к конкретной версии игры (BNE 2.02). Не используйте на публичных серверах — это несовместимо с серверным античит-плагином.

## Установка инструментов (с нуля)

Понадобится Windows 10/11. Все шаги — однократные.

### 1. Rust

1. Скачайте установщик с официального сайта: https://rustup.rs/ (кнопка **Download rustup-init.exe (32-bit/64-bit)** — берите 64-bit).
2. Запустите `rustup-init.exe`, в консоли нажмите `1` (стандартная установка) и дождитесь конца.
3. Закройте и заново откройте терминал. Проверьте:

```powershell
cargo --version
```

### 2. Build Tools для Visual Studio (линкер)

Rust под Windows собирает через компоненты Visual Studio:

1. Скачайте **Build Tools для Visual Studio 2022**: https://visualstudio.microsoft.com/downloads/ (раздел «Tools for Visual Studio» → «Build Tools for Visual Studio 2022»).
2. При установке отметьте рабочую нагрузку **«Desktop development with C++»** (достаточно её одной).
3. Если у вас уже стоит Visual Studio 2022 (любой редакции) с C++ — этот шаг пропустите.

### 3. 32-битная цель компиляции

Игра 32-битная, поэтому добавьте соответствующий таргет (один раз):

```powershell
rustup target add i686-pc-windows-msvc
```

## Сборка

```powershell
cd путь\к\War2ModRust
.\build32.cmd
```

Скрипт сам подключает окружение Visual Studio и вызывает `cargo build --release`. Готовый файл **`victory.w2p`** появится в корне проекта.

> Если в начале вывода видите «Не удается найти указанный файл» — это безобидное сообщение vcvars, игнорируйте. Главное — строка `Finished release` в конце.

Если Visual Studio установлена не в стандартное место, поправьте путь к `vcvars32.bat` внутри `build32.cmd`.

## Установка мода в игру

1. Убедитесь, что у вас Warcraft II BNE версии **2.02** с загрузчиком `.w2p`-плагинов (из комплекта war2mod/оригинального проекта).
2. Скопируйте `victory.w2p` в папку плагинов игры (туда же, куда ставится оригинальный C++ плагин).
3. Запустите игру — мод активируется при старте миссии.

## Как написать свой мод

1. Откройте `src/victory.rs` — там 52 пустых триггера (`v_human1` … `v_xorc12`) и `v_custom` для пользовательских карт.
2. Напишите свои условия победы, используя API мода: поиск юнитов (`find.rs`, `sort.rs`), приказы (`orders.rs`), сообщения (`show_message` в `game.rs`), ресурсы (`player.rs`) и т.д.
3. Готовые примеры — закомментированные `example1–6` в конце `src/victory.rs`; воссстановленные оригинальные условия всех миссий — в файле `original war2 triggers.cpp` [оригинального репозитория](https://github.com/Mistral-war2ru/War2Mod) (справочник, в сборку не входит).
4. Пересоберите: `.\build32.cmd`.

## Структура проекта

| Модуль | Назначение |
|---|---|
| `src/lib.rs` | Точка входа, экспорт `w2p_init` |
| `src/defs.rs`, `src/names.rs` | Адреса функций/данных игры, константы юнитов/спеллов |
| `src/patch.rs` | Примитивы заплаток (call/jmp/байты), WinAPI |
| `src/state.rs` | Глобальное состояние мода, таблицы кнопок |
| `src/game.rs`, `src/find.rs`, `src/sort.rs`, `src/orders.rs` | API игры: вызовы функций, поиск и фильтрация юнитов, приказы |
| `src/mechanics.rs`, `src/player.rs`, `src/combat.rs` | Порталы, рунные камни, паладины, ауры, захват, кража ресурсов |
| `src/damage.rs`, `src/tick.rs` | Хуки урона, игровой тик |
| `src/ai.rs`, `src/aitick.rs` | Исправления и поведение ИИ |
| `src/buildui.rs`, `src/heroes.rs`, `src/uihooks.rs`, `src/place.rs` | Кнопки строительства, герои, rally points, размещение зданий |
| `src/net.rs` | Сетевая синхронизация (чит-пакеты) |
| `src/victory.rs` | Триггеры победы (здесь пишется ваш мод) |
| `src/init.rs` | Установка хуков, инициализация |
| `src/fixes.rs`, `src/saveload.rs` | Фиксы движка, save/load |
